# Fall Arena

A six-player party brawler set in an orbital arena. Knock everyone off the floating glass floor and be the last one standing.

**Play:** https://fzthjcs556-coder.github.io/cloud-game-builder/fall-arena/

## Play online with friends
1. Tap **Play online with friends**, type your name, and tap **Create a room**.
2. Send your friends the 4-letter room code, or tap **Copy invite link** and send the link.
3. Friends open the link (or enter the code and tap **Join**) and pick a fighter.
4. When everyone is in, the host taps **Start**. 2 to 6 players.

The host's phone runs the match, so the host should keep the game open in the front until the show ends.

## Fighters
| Fighter | Ability |
|---|---|
| Survivor | Triple Jump: one extra jump in the air |
| Zombie | Iron Body: takes 25% less knockback, a little slower |
| Cyborg | Shock Combo: the 3rd punch hits 50% harder |
| Rogue | Strong Arm: longer grab, throws fly 30% farther |
| Ranger | Swift: 15% faster, dash recharges quicker |
| Skater | Air Ace: faster dive, bigger ground slam |
