# Project rules

## Push after every completed task
This repository is worked on from both a MacBook and Claude Code cloud sessions.
The only thing they share is GitHub, so work that is not pushed is lost when a
cloud session ends.

- After every completed piece of work, commit it and push it to GitHub
  (`git push -u origin <branch>`) without waiting to be asked.
- After pushing, tell the user the branch name so they can `git pull` it on the MacBook.
- Keep commits small and focused: one completed task per commit.

## Skills
Project skills live in `.claude/skills/<skill-name>/SKILL.md` so they are
available in every cloud session on this repository.
